# 録画動画をドラッグ＆ドロップしてユーザーアプリへ連携する

対応OS：Windows 10/11、Windows PowerShell 5.1。Python/YOLOは従来の研究用環境を使用します。

## 1. 最初の更新

PowerShellで以下を実行します。

~~~powershell
git -C "$env:USERPROFILE\parking-guide-admin" pull --ff-only
~~~

エクスプローラーで **%USERPROFILE%\parking-guide-admin\parking-vision** を開き、
**録画YOLO_ドラッグして開始.cmd** をダブルクリックします。

初回は、そのフォルダの録画専用設定 \`config_video_demo.json\` が必要です。
存在しなければ先に \`regenerate_lab_assets.py\` で作成してください。

## 2. 動画をつかんで入れる

ウィンドウの大きな青い枠にMP4などをドラッグ＆ドロップします。
「ファイルを選ぶ」ボタンでも選択できます。
動画を置いた時点では解析やクラウド送信は始まりません。

研究室PCに移行したモデル \`best_from_usb.pt\` を使用するときは
「使用するYOLOモデルを選ぶ」でモデルを選び、読み込み確認と保存を行います。
旧設定はバックアップを取り、録画専用設定のモデルパスだけ変更します。

## 3. 6区画を動画に合わせる

「登録済みの6区画を取り込む・照合する」を押して、
ノートPCから移した \`config_usb_original.json\` などを指定します。
録画の最初のフレームに6区画が重なります。

- 完全に一致：映像ウィンドウで \`S\` を押して保存
- ずれている：\`Q\` で中止し、「動画の画角で6区画を新規登録」を使用

カメラの位置、向き、レンズ、ズームが異なる場合は、たとえ縦横比が同じでも
旧カメラの区画をそのまま使用しないでください。
新規登録は4点ずつ区画を選択し、\`Q\` で保存、\`Esc\` で中止です。
どちらも \`home-test-001\` の実カメラ設定を変更しません。

## 4. ユーザーアプリとの共有

必ず先に「PCだけで判定する」で映像と区画が一致するか確認してください。

「ユーザーアプリと連携して開始」を選ぶと、
Windowsの確認画面と別のPowerShell画面が開きます。
さらに \`録画共有\` と入力し、Supabase管理者アカウントでログインします。
動画の上に重ねた6区画の確認ウィンドウで \`S\` を押して承認した後、
YOLOが状態を計算し、**録画実演専用施設 \`home-video-demo-001\`** へ
\`parking_live_status\` と車両追跡セッションを送ります。
判定送信が成功した場合のみ、この専用施設の \`parking_live_visibility\` をONにします。

ユーザーアプリ：

https://t21j075dz-alt.github.io/parking-guide-user/

施設一覧で **実験用駐車場（自宅駐車場録画用）** を選択します。
録画のため「実際の現在の空き情報ではありません」と明示しています。
録画YOLOの送信が有効な間は、区画の満空と停車・駐車・退出候補を表示します。
ユーザーアプリはおよそ3秒おきに判定状態を確認し、
20秒以上更新されない区画は未確認にします。
新たに追加した連携状態パネルから、共有OFF・共有中・更新停止も確認できます。

GUIの「共有の状態を確認」でも、録画施設の公開状態と新しい受信区画数を確認できます。
**録画の映像ファイル自体はSupabaseへアップロードしません。**

## 5. 停止

判定動画の画面で \`Q\` を押すと、解析を停止して録画・CSVを閉じます。
共有していた場合、プログラムは録画用施設の公開状態をOFFに戻します。
通信障害などでOFFへの更新に失敗する可能性があるため、
**必ずユーザーアプリで「共有停止」または「未確認」になったことを確認**してください。
異常終了時でも20秒以上前の判定を空きとして使わない設計ですが、
公開フラグ自体がONのまま残る可能性があります。

同じ施設IDへ他のPCから同時共有しないでください。
実験を止めても旧データを「現在の空き」として扱わないようにします。

## 6. エラーの場合

- モデルがありません：GUIの「使用するYOLOモデルを選ぶ」で \`best_from_usb.pt\` を指定
- 区画0件：GUIの区画取り込みまたは新規登録を実行
- 6区画がずれる：旧区画の流用を中止し、動画上で再登録
- 共有がONにならない：管理者ログイン、RLS権限、通信を確認。GUIの「共有の状態を確認」
- 音声・案内を含むユーザーアプリの最新表示が出ない：インターネット接続を確認して、
  PWAの更新通知が出ていれば停車中に更新

GUI・連携はGitHubへ追加済みですが、研究室PC上での実機起動テストは別途必要です。
