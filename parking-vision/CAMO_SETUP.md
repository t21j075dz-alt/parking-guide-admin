# Camo（iPhone）を自宅駐車場に接続する手順

この手順は `parking-vision` フォルダで使用します。既存のUSBカメラ用 `config.json` は変更しません。

## 事前準備
- iPhoneのCamo CameraとPCのCamo Studioを接続し、Camo仮想カメラを有効にする。
- WindowsでPython/OpenCV/Ultralyticsが使えることを確認する。
- PCで `parking-vision` フォルダへ移動する。
- `-Python` には普段YOLO実験に使用している `python.exe` のフルパスを指定できる。

## 1. Camo映像を選択
PowerShellで以下を実行します（`python.exe` の指定は必要な場合のみ）。

```powershell
.\start.ps1 -Mode camo-setup
```

映像を取得できるカメラ番号が一覧に表示されます。iPhone/Camoの映像を実際にプレビューし、目視で正しいことを確認してから「はい」を入力します。
`config_camo.json` が新規作成されます。管理アプリ用の施設IDは `home-test-001`、カメラIDは `home-camo-01` です。

> 現在のCamo画像が狭く見える場合は、Camo Studioで適切なレンズ（端末対応時は超広角を含む）を選び、ズーム・クロップを確認してください。PC上で画像を引き伸ばしても、カメラの実画角は広がりません。

## 2. Camo専用の駐車区画を登録
```powershell
.\start.ps1 -Mode camo-zones
```
プレビューの上で**実際に映っている区画**だけ四隅をクリックします。自宅に8区画登録していても、カメラに映らない区画は空車とみなさず登録を飛ばします。

- 左クリック4回：区画を登録
- S：映らない区画を飛ばす
- E：入場エリア登録
- X：出場エリア登録
- Q：登録を保存
- Esc：キャンセル

保存時に、カメラ番号・映像サイズ・縦横比を区画設定と一緒に保存します。撮影場所・方向・iPhoneのレンズやズーム設定が変わった場合は必ず区画を再登録してください。

## 3. ローカルテスト（クラウドへ送信しません）
```powershell
.\start.ps1 -Mode camo-test
```
リアルタイムのYOLO検出、追跡ID、駐車区画の色が現実と合っているか確認します。Qで終了します。

録画は従来どおりローカルPCの `%LOCALAPPDATA%\ParkingResearch\Recordings` に保存します。
カメラの元映像・判定付き動画・区画状態ログは別々に記録されます。

## 4. 管理アプリへライブ送信（本人確認後）
```powershell
.\start.ps1 -Mode camo-live
```
「共有」と入力し、Supabaseの管理者アカウントでログインすると、
`parking_live_status` と `parking_vehicle_sessions` に状態情報を送ります。
ログインできる管理者の権限があること、`config_camo.json` の
`supabase_url` / `publishable_key` と `vehicle_model` が正しいことを確認してください。
ローカル録画の映像やナンバープレート画像はクラウドへ送信しません。

最初は自宅施設の「利用者向け公開」はOFFです。管理者画面で現場と状態が一致したことを確認した後、必要な場合のみ手動で公開してください。更新が途絶えた場合は利用者側で「確認できない」と表示する既存の安全対策を使います。

## 映像サイズ・見切れへの対応
- **デフォルトはカメラが実際に返すサイズを採用**：ソースに勝手な16:9/4:3の切り抜きを強制しません。
- `camera_capture_width`, `camera_capture_height` がともに0なら、Camo/カメラが出すフレームをそのまま使います。
- カメラ機器側が要求した解像度に対応している場合だけ、例：`1920` / `1080` と両方を設定できます。ドライバーによっては変更できない場合があります。
- `camera_preview_max_width` / `camera_preview_max_height` で**表示のみ**縮小します。録画と検出は元画像の縦横比を保ちます。
- 縦横比が変化した場合は誤った枠案内を防ぐためライブ処理を停止します。
- カメラの画角が広がるわけではありません。**超広角レンズの有無は端末とCamo側の設定によります。**

## 注意事項
- CamoをWi-Fi/テザリングで接続する場合、途中で通信が切れると判定が止まります。
- `config_camo.json` とログイン情報、映像はGitHubに公開しないでください。
- 以前のUSB用 `config.json`、研究データ、モデル重みは上書きしません。
- 異なるカメラとカメラ位置では、たとえ画像の縦横比が一致しても、区画座標の再登録が必要です。
- カラーコーンやカートは、対応する学習済み障害物モデルがなければ検出できません。
- 検出結果と追跡IDは実験上の推定です。駐車・退出の確実な証明にはなりません。
