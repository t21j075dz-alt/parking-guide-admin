# 管理用アプリ

駐車場マップを作成・編集するための管理者専用Webアプリです。利用者向けの施設検索・区画案内画面は含みません。

## 主な機能

- 施設選択
- 普通車・軽・車椅子使用者用・EV区画の配置
- 車道・歩道・横断歩道の配置
- 建物・建物出入口・駐車場出入口の配置
- ドラッグ移動、回転値編集、複製、削除
- 建物出入口の名称、入口種類、一般利用可否、車椅子可否、案内基準、buildingIdの編集
- キャンバスサイズと `scaleMetersPerPixel` の設定
- ブラウザー内保存
- JSONの読込・出力
- ユーザー用 `parking-layouts.js` の出力
- ライト／ダークモード

`ユーザー用JS出力` で生成したファイルを `../user-app/parking-layouts.js` と置き換えてください。
